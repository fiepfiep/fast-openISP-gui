    ISP modules¶

    The pipeline has three domains:

    1. Bayer domain (DPC → CNF): works on the raw mosaic, one color channel at a time.
    2. RGB domain (CFA → GAC): CFA demosaics into linear RGB; GAC applies gamma and converts to 8 bit.
    3. YCbCr domain (CSC → BCC): CSC converts to luma and chroma, so the filters that follow can work on luma (Y) and chroma (CbCr) separately.

    SCL (scaler) resizes the final result.

    At a glance¶

    Module What it does
    DPC Replaces pixels that differ strongly from all 8 same-color neighbours (hot or dead pixels).
    BLC Subtracts the sensor's black level from each channel; optional R→Gr / B→Gb crosstalk correction.
    AAF Light 3 × 3 smoothing per channel to reduce aliasing before demosaicing.
    AWB White balance: multiplies each channel by a gain (manual or grey-world).
    CNF Chroma noise filter: suppresses isolated red or blue noise in dark areas, depending on the AWB gains.
    CFA Demosaicing: interpolates full RGB from the mosaic (Malvar-He-Cutler or bilinear).
    CCM Color correction matrix: maps sensor RGB to the output color space.
    GAC Gain and gamma curve; converts linear data to 8-bit display values.
    CSC Converts RGB to YCbCr (BT.601).
    NLM Non-local means denoising of luma. Strong, but the slowest module.
    BNF Bilateral denoising of luma, which keeps edges sharp.
    CEH Local contrast enhancement (CLAHE) on luma.
    EEH Edge enhancement (sharpening) of luma.
    FCS False color suppression: reduces chroma along strong edges.
    HSC Hue rotation and saturation.
    BCC Brightness and contrast.
    SCL Resizes the result to a fixed output size.

    Parameter reference¶

    This section is generated from the configuration models in fast_openisp.config, so it always matches the code.

    DPC — Dead Pixel Correction¶

    Enabled by default: yes.

    Parameter Type Range Default Description
    diff_threshold int ≥ 0, ≤ 65535 30 Min difference to all 8 neighbours to flag a dead pixel

    BLC — Black Level Compensation¶

    Enabled by default: yes.

    Parameter Type Range Default Description
    bl_r int ≥ 0, ≤ 65535 0 Black level of R pixels (subtracted)
    bl_gr int ≥ 0, ≤ 65535 0 Black level of Gr pixels (subtracted)
    bl_gb int ≥ 0, ≤ 65535 0 Black level of Gb pixels (subtracted)
    bl_b int ≥ 0, ≤ 65535 0 Black level of B pixels (subtracted)
    alpha float ≥ -1, ≤ 1 0.0 R→Gr crosstalk compensation
    beta float ≥ -1, ≤ 1 0.0 B→Gb crosstalk compensation

    AAF — Anti-Aliasing Filter¶

    Enabled by default: yes.

    No parameters.

    AWB — Auto White Balance¶

    Enabled by default: yes.

    Parameter Type Range Default Description
    mode manual | grey_world manual manual: use the gains below; grey_world: estimate gains per image
    r_gain float ≥ 0, ≤ 8 1.0 Gain for R pixels
    gr_gain float ≥ 0, ≤ 8 1.0 Gain for Gr pixels
    gb_gain float ≥ 0, ≤ 8 1.0 Gain for Gb pixels
    b_gain float ≥ 0, ≤ 8 1.0 Gain for B pixels

    CNF — Chroma Noise Filter¶

    Enabled by default: yes.

    Parameter Type Range Default Description
    diff_threshold int ≥ 0, ≤ 65535 0 Chroma noise detection threshold (uses the AWB gains)

    CFA — Demosaicing (CFA interpolation)¶

    Enabled by default: yes.

    Parameter Type Range Default Description
    mode malvar | bilinear malvar Demosaicing algorithm

    CCM — Color Correction Matrix¶

    Requires CFA.

    Enabled by default: yes.

    Parameter Type Range Default Description
    ccm 3×4 matrix identity 3×4 matrix: rows are output R, G, B; columns are input R, G, B and offset

    GAC — Gamma Correction¶

    Requires CFA.

    Enabled by default: yes.

    Parameter Type Range Default Description
    gain float ≥ 0, ≤ 16 1.0 Linear gain applied before the gamma curve
    gamma float > 0, ≤ 4 0.42 Gamma exponent (output = input^gamma)

    CSC — Color Space Conversion¶

    Requires GAC.

    Enabled by default: yes.

    No parameters.

    NLM — Non-Local Means Denoising¶

    Requires CSC.

    Enabled by default: yes.

    Parameter Type Range Default Description
    search_window_size int ≥ 3, ≤ 21 9 Search window size (odd)
    patch_size int ≥ 1, ≤ 9 3 Patch size (odd)
    h float > 0, ≤ 100 10 Filter strength; larger smooths more

    BNF — Bilateral Noise Filter¶

    Requires CSC.

    Enabled by default: yes.

    Parameter Type Range Default Description
    intensity_sigma float > 0, ≤ 10 0.8 Range sigma; larger smooths more
    spatial_sigma float > 0, ≤ 10 0.8 Spatial sigma; larger smooths more

    CEH — Contrast Enhancement (CLAHE)¶

    Requires CSC.

    Enabled by default: yes.

    Parameter Type Range Default Description
    tiles 2 × int (4, 6) Number of tiles (rows, columns), each ≥ 2
    clip_limit float ≥ 0, ≤ 1 0.01 Histogram clip limit (fraction)

    EEH — Edge Enhancement¶

    Requires CSC.

    Enabled by default: yes.

    Parameter Type Range Default Description
    edge_gain float ≥ 0, ≤ 16 1.5 Gain applied to strong edges
    flat_threshold int ≥ 0, ≤ 255 4 Deltas ≤ this are set to 0
    edge_threshold int ≥ 0, ≤ 255 8 Deltas > this get the full gain
    delta_threshold int ≥ 0, ≤ 255 64 Maximum enhancement delta

    FCS — False Color Suppression¶

    Requires CSC, EEH.

    Enabled by default: yes.

    Parameter Type Range Default Description
    delta_min int ≥ 0, ≤ 255 8 Edge strength where suppression starts
    delta_max int ≥ 0, ≤ 255 32 Edge strength of full suppression

    HSC — Hue / Saturation Control¶

    Requires CSC.

    Enabled by default: yes.

    Parameter Type Range Default Description
    hue_offset float ≥ -180, ≤ 180 0 Hue rotation in degrees
    saturation_gain float ≥ 0, ≤ 4 1.0 Saturation multiplier

    BCC — Brightness / Contrast Control¶

    Requires CSC.

    Enabled by default: yes.

    Parameter Type Range Default Description
    brightness_offset int ≥ -255, ≤ 255 0 Added to luma
    contrast_gain float ≥ 0, ≤ 4 1.0 Contrast multiplier around median

    SCL — Scaler¶

    Requires CFA.

    Enabled by default: no.

    Parameter Type Range Default Description
    width int > 0, ≤ 32768 1920 Output width in pixels
    height int > 0, ≤ 32768 1080 Output height in pixels
